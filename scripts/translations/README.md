# Translations

- `fetch_quranenc.py`: QuranEnc.com API -> `public/tr/<key>/<sura>.json` (`{"t":[...], "f":[...footnotes]}`), text unaltered (QuranEnc licence: no changes, credit publisher + QuranEnc.com, show version). Metadata in `public/tr/quranenc.json`.
- `build_list.py`: -> `src/data/translations.json` (language order, native language name, translator, size, credit line with version).
- Musayev and Kuliev stay as Tanzil single files (`public/tr/<id>.json`).
